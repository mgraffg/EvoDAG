The model and the ensemble
==========================

:py:mod:`EvoDAG.model`
----------------------

Everything a user needs to train and predict: :py:class:`~EvoDAG.model.EvoDAGE`
(the ensemble with the ``fit``/``predict`` interface),
:py:class:`~EvoDAG.model.Ensemble` and :py:class:`~EvoDAG.model.Model` (what a
fit returns) and :py:class:`~EvoDAG.model.EvoDAG` (a single model; not the
engine of :py:mod:`EvoDAG.base`, which has the same name).
